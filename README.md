# Jetacy: Elevating Business Aviation

Building a Landing Page for Jetacy. 

Jetacy is a centralized operating system for business jet detailing services, designed to eliminate operational friction by connecting Clients, Fleet Ops & Detailing Crews through three dedicated interfaces on one execution layer. Not a Market Place, preserving discretion & reliability.

Integrated real-time traffic sync, automated tail lookups, dynamic scheduling, live digital job cards, crew GPS tracking, performance profiles & financial tracking that digitize the entire detailing lifecycle & simplify the workflow to deliver seamless turnaround execution.

Engineered to empower specialized aircraft detailers, alongside FBOs & Fleet Ops, providing operational transparency & speed for BizAv presentation & care services.

The app is 90% done, considered complete, The Landing page will have a brief simple one pager, defining who we are, and has "Request Demo", Contact (calendaly) schedule, our @connector:linkedin:"LinkedIn" link, our vision and mission. our problem solution, how detailers are used to manual coordination. + Provide effective ideas to add to the page

## Development

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```

Images are served locally from `public/images`. Set `VITE_SITE_URL` in `.env`
to your production origin for canonical links and absolute social sharing URLs
(see `.env.example`).

Run `npm run build` to create the Node server and static files in `.output`.
Start the production server with `node .output/server/index.mjs`.
